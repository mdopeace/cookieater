Cookies, under control.

Cookieater is a compact Chrome extension for viewing, searching, and managing cookies for the site you're on.

Install manually

Build from source

Requires Node.js and pnpm.

git clone https://github.com/mdopeace/cookieater.git
cd cookieater
pnpm install && pnpm build

The build creates the unpacked extension in .output/chrome-mv3.

Load it in Chrome

Chrome or another Chromium-based browser.

  1. Open chrome://extensions and turn on Developer mode.
  2. Choose Load unpacked.
  3. Select the project's .output/chrome-mv3 folder.

Privacy and permissions

Does Cookieater send my cookies anywhere?

No. Cookieater reads and writes cookies in your browser and does not send cookie data to a Cookieater server. See the privacy policy.

Why does it need these permissions?

The cookies permission uses the browser's cookie API. <all_urls> lets the extension identify the active tab's hostname and access that site's cookies.

Which cookies does it show?

It lists cookies for the domain shown in the popup. That domain defaults to the active tab's hostname and can be edited.

What browsers are supported?

Chrome and Chromium-based browsers that support Manifest V3 extensions.
